## 🌟 نظرة عامة (Overview)

قالب **كود التطور** هو قالب ووردبريس حصري وخاص بالمنصة التعليمية **كود التطور (Code Elta6ur)**.  
تم بناؤه من الصفر ليكون **فائق السرعة، خفيف الوزن، ومستقلاً تماماً عن أطر العمل الثقيلة (Zero Heavy Frameworks)**، مع توفير تجربة مستخدم عربية أصيلة (Arabic-First RTL) وتكامل سلس مع محرر Gutenberg عبر أنماط الكتل الجاهزة (Block Patterns).

---

## 🚀 المميزات الرئيسية (Core Features)

1. **الاستقلالية والسرعة الفائقة (High Performance & Zero Dependencies):**
   - لا يعتمد على jQuery أو React أو Bootstrap في واجهة الزائر.
   - يعتمد بنسبة 100% على **Vanilla JS (ES6+)** النقي و **CSS Grid / Flexbox** مع الخصائص المنطقية (CSS Logical Properties).
   - سرعة تحميل فائقة وأداء قياسي (PageSpeed Score 95+).

2. **المركزية في لوحة التخصيص (Centralized Customizer):**
   - لوحة تحكم كاملة داخل `المظهر -> تخصيص -> 🎨 إعدادات منصة كود التطور`.
   - إدارة مركزية لجميع بيانات التواصل: البريد، الهاتف، الواتساب، التيليجرام، معرف وقناة يوتيوب، إنستغرام، فيسبوك، وجيت هاب.
   - التحكم الكامل بنصوص وعناوين الهيرو وأزرار اتخاذ الإجراء (CTA) ونصوص الفوتر بدون لمس كود PHP واحد.

3. **أنماط Gutenberg أصلية (Native Block Patterns):**
   - تصنيف خاص داخل محرر المكونات: **أنماط كود التطور | Code Elta6ur**.
   - أنماط جاهزة بضغطة زر واحدة تشمل:
     - بانر الهيرو الترحيبي (Hero Section).
     - قسم أهداف ومميزات المنصة (Features & Goals).
     - شبكة الكورسات التدريبية (Courses Grid).
     - بانر الدعوة لاتخاذ الإجراء (Global CTA).
   - **النتيجة:** إنشاء صفحات جديدة كلياً بتصميم المنصة الفخم دون الحاجة إلى استخدام Elementor إطلاقاً.

4. **التعايش السلمي مع صفحات Elementor السابقة (Elementor Compatibility Layer):**
   - يدعم الصفحات القديمة المبنية بـ Elementor دون أي كسر في التنسيقات أو البيانات.
   - غلاف برمجي ذكي (`cdt-has-elementor` و `cdt-elementor-wrapper`) يفصل بين الصفحات القديمة والصفحات الجديدة تلقائياً.

5. **معالجة الروابط وتوجيه 301 التلقائي (SEO & 301 Redirects):**
   - معالجة تلقائية للروابط المعطوبة السابقة وتوجيهها 301 لحماية أرشفة محركات البحث و Google Search Console.
   - بيانات منظمة تلقائية Schema.org JSON-LD للمقالات والمؤسسة التعليمية بدون تعارض مع إضافات السيو.

6. **ميزات تفاعلية حديثة للمبرمجين:**
   - زر نسخ الأكواد البرمجية بنقرة واحدة (One-Click Code Copy) في جميع المقالات مع تنبيه فوري "تم النسخ!".
   - مشغل فيديو يوتيوب منبثق فائق الخفة (Video Lightbox Modal).
   - حساب تقديري لوقت القراءة للمحتوى العربي (Estimated Reading Time).
   - شريط إحصائيات المنصة ومسار تتبع تنقل مهيأ للسيو (Breadcrumbs).

## 🛠️ التثبيت والتفعيل (Installation)

### الطريقة الأولى: عبر لوحة تحكم ووردبريس (WordPress Dashboard)
1. اضغط المجلد `code-elta6ur-theme` في ملف مضغوط بصيغة `code-elta6ur-theme.zip`.
2. ادخل إلى لوحة تحكم ووردبريس (`/wp-admin/`).
3. توجه إلى: **المظهر (Appearance)** -> **قوالب (Themes)** -> **أضف قالب جديد (Add New)**.
4. اضغط على **رفع قالب (Upload Theme)** ثم اختر ملف `code-elta6ur-theme.zip`.
5. اضغط على **التنصيب الآن (Install Now)** ثم **تفعيل (Activate)**.

### الطريقة الثانية: عبر مدير الملفات أو FTP (Hostinger / cPanel / hPanel)
1. ارفع مجلد `code-elta6ur-theme` مباشرة إلى المسار:
   `/wp-content/themes/code-elta6ur-theme/`
2. ادخل إلى لوحة التحكم: **المظهر** -> **قوالب**.
3. ستجد قالب **كود التطور | Code Elta6ur** متاحاً مع لقطة المعاينة الخاصة به، اضغط **تفعيل**.

## 🧩 كيفية استخدام أنماط كود التطور في Gutenberg

عند إضافة أو تعديل أي صفحة أو مقال:
1. افتح محرر المكونات (Block Editor).
2. اضغط على علامة الزائد `+` في الزاوية العلوية لإضافة كتلة.
3. انتقل إلى تبويب **أنماط (Patterns)**.
4. اختر تصنيف **أنماط كود التطور | Code Elta6ur**.
5. انقر على أي نمط (مثل: `بانر الهيرو الرئيسي`، أو `أهداف ومميزات المنصة`) لتدرجه فوراً في صفحتك بتنسيق نظيف وسريع!

## 🔒 متطلبات النظام والأمان
- **إصدار ووردبريس:** WordPress 6.0 فما فوق (مختبر بالكامل على 6.7).
- **إصدار PHP:** PHP 8.0 فما فوق (موصى به PHP 8.2 / 8.3).
- **معايير الأكواد:** متوافق بنسبة 100% مع معايير ووردبريس (WordPress Coding Standards - WPCS).
- **الحماية:** فحص كامل للـ Nonces، تعقيم المدخلات (`sanitize_*`)، وهروب المخرجات (`esc_*`) لمنع ثغرات XSS و CSRF.
