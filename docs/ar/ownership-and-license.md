## 2. شروط ونطاق الاستخدام

1. **مواد التوثيق ومعرض الأعمال فقط:**
   المواد المنشورة في هذا المستودع مقدمة حصرياً لأغراض الاطلاع والتقييم المهني لمعرض الأعمال.

2. **عدم منح أي ترخيص للبرنامج الأصلي:**
   قالب ووردبريس الخاص بمنصة كود التطور، وشيفرته المصدرية، وأصوله، وتصميم قواعد بياناته، وملفات تنفيذه **ليست مشمولة** في هذا المستودع و**غير مرخصة** للاستخدام أو النسخ أو التعديل أو إعادة التوزيع أو الاستغلال التجاري تحت أي ظرف.

3. **انعدام الحقوق الضمنية:**
   لا يمنح تصفح هذا المستودع أو الاستشهاد به أي حقوق في براءات الاختراع أو العلامات التجارية أو الأسرار التجارية للمنصة.

4. **العلامات التجارية للجهات الخارجية:**
   تعد WordPress® علامة تجارية مسجلة لمؤسسة ووردبريس. جميع الأسماء والعلامات التجارية الأخرى المذكورة هي ملك لأصحابها وذكرها هنا لأغراض الوصف الهندسي والمعماري فقط دون أي تبعية أو ادعاء بالشراكة.
