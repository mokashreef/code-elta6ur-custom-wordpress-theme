## 1. نظرة عامة على المشروع (Project Overview)

**منصة كود التطور** ([code-elta6ur.com](https://code-elta6ur.com/)) هي منصة تعليمية عربية متخصصة في علوم الحاسوب وهندسة البرمجيات وتطوير الويب.

لتوفير تجربة تعليمية فائقة السرعة وعالية التناسق، تم تطوير قالب ووردبريس مخصص بالكامل من الصفر (`code-elta6ur-theme`، الإصدار 1.2.5). يحل هذا الحل الهندسي محل بناة الصفحات الثقيلة والإضافات المتضاربة عبر إطار عمل موحد وخفيف الوزن يتكامل مباشرة مع نواة ووردبريس الرسمية.

### أبرز المؤشرات والمزايا الهندسية:
- **خلو تام بنسبة 100% من أطر العمل الثقيلة:** القالب لا يستخدم jQuery أو Bootstrap أو مكتبات React الثقيلة في واجهة زوار الموقع.
- **الواجهة الأمامية النقية:** تعتمد كلياً على **Vanilla JavaScript (ES6+)** مع استغلال واجهات الويب البرمجية الحديثة الأصلية في المتصفح (IntersectionObserver, Page Visibility, Clipboard, Web Storage).
- **معمارية التنسيق الحديثة:** استخدام كامل لـ CSS Grid و Flexbox مع الخصائص المنطقية (CSS Logical Properties) لدعم التايبوجرافي العربي الأصيل (RTL) وثنائي الاتجاه بأعلى كفاءة.
- **نظام التصميم ومحددات الهوية (Design Tokens):** سياسة لونية صارمة تحظر استخدام درجات البنفسجي، وترتكز على لوحة الأزرق التقني والسماوي المتدرج المتزن (`#0170B9`, `#3EA3E8`, `#004A7D`, `#3B82F6`, `#38BDF8`).
- **أنماط كتل Gutenberg الأصلية (Block Patterns):** مكتبة كتل جاهزة تمنح إدارة المحتوى مرونة بصرية كاملة دون استهلاك موارد الخادم أو تضخيم الشيفرة.
- **جناح التحقق المؤتمت:** جناح اختبارات مستقل يعمل عبر سطر الأوامر (PHP CLI) يتحقق بنسبة 100% من سلامة التسجيلات والمخططات والأمان البرمجي.

## 2. الأهداف الهندسية وفلسفة التطوير

1. **السرعة القصوى وتقليل البصمة البرمجية:** التخلص من حجب الرندر (Render-blocking)، والطلبات الشبكية الزائدة، والتداخل المفرط في شجرة عناصر الـ DOM.
2. **التايبوجرافي العربي وإمكانية الوصول (Accessibility):** ضبط دقيق للخطوط العربية (خط Cairo للعناوين والنصوص، وخطوط أحادية المسافة للأكواد البرمجية) مع الالتزام بمعايير WCAG 2.1 AA.
3. **فصل الأنظمة والتضمين المعياري:** بناء ميزات المنصة المتقدمة (أدوات المطورين، محاكي الأكواد، نظام التحفيز) كأنظمة فرعية مستقلة داخل القالب بدلاً من تراكم الإضافات الخارجية.
4. **التعايش السلمي وعدم كسر المحتوى السابق:** دعم صفحات Elementor السابقة عبر طبقة عزل خاصة لمنع تشوهها، مع خدمة الصفحات الجديدة بأكواد نظيفة كلياً.
5. **الأمان الصارم (Zero-Trust Security):** احتساب النقاط الحساسة على الخادم، وتأمين المعاملات ضد التكرار (Idempotency)، وعزل بيئة تشغيل الأكواد البرمجية عن الخادم المضيف.

## 3. المعمارية العامة للنظام (Architecture Overview)

يعتمد النظام على فصل صارم للمسؤوليات يتدرج من واجهة العرض إلى الأنظمة الفرعية وإدارة الخيارات وقواعد البيانات:

```mermaid
graph TD
    subgraph Client Layer [طبقة العرض والزائر - بدون أطر عمل ثقيلة]
        A1[قوالب HTML5 الدلالية] --> A2[وحدات Vanilla JS البرمجية]
        A2 --> A3[متغيرات التصميم CSS والدعم العربي RTL]
    end

    subgraph Platform Subsystems [نواة أنظمة المنصة داخل القالب]
        B1[جناح أدوات المطورين - 30 أداة]
        B2[محاكي الأكواد التفاعلي - 15 لغة]
        B3[نظام الحسابات والتحفيز والتقدم التعليمي]
        B4[جناح صحة الـ SEO وإدارة الأرشفة]
        B5[محرك أنماط كتل Gutenberg الجاهزة]
    end

    subgraph Service & Isolation Layer [طبقة الخدمات والعزل]
        C1[محدد مشغلات التنفيذ - Piston / Judge0 / JDoodle]
        C2[طبقة التعايش وعزل صفحات Elementor السابقة]
        C3[لوحة التخصيص المركزية Customizer]
    end

    subgraph WordPress Core & Storage [نواة ووردبريس وقواعد البيانات]
        D1[محرك الاستعلامات والتوجيه ووردبريس]
        D2[جداول النواة الأساسية: wp_users, wp_posts]
        D3[جداول مخصصة: سجل النقاط، تقدم الدروس، الشارات، الجلسات]
    end

    Client Layer --> Platform Subsystems
    Platform Subsystems --> Service & Isolation Layer
    Service & Isolation Layer --> WordPress Core & Storage
```

للاطلاع على الشرح المعماري المفصل، راجع [docs/ar/architecture.md](docs/ar/architecture.md).

## 4. الأجنحة والأنظمة الوظيفية الرئيسية

### أ) جناح أدوات المطورين (30 أداة برمجية متخصصة)
حزمة متكاملة من 30 أداة ويب موجهة لمهندسي البرمجيات والطلاب وممارسي DevOps، مقسمة على 7 مجالات:
- **بيانات JSON والبيانات المهيكلة:** منسق JSON، مقارن الفروقات (Diff)، مدقق المخططات، فاحص JSONPath، محول YAML/JSON، ومولد الشيفرات من JSON.
- **الشبكات وواجهات الـ API:** محول cURL إلى لغات البرمجة، مدقق مواصفات OpenAPI، مقارن إصدارات OpenAPI، وتوليد واجهات TypeScript.
- **الحماية والمصادقة:** فاحص ومحلل توكنات JWT، محلل ترويسات HTTP، فاحص الترويسات الأمنية وفق OWASP، مولد سياسات CSP، ومعالج ملفات `.env`.
- **النصوص والتعبيرات النمطية (Regex):** مختبر التعبيرات النمطية المباشر، ومولد الأنماط الشائعة.
- **قواعد البيانات و SQL:** منسق استعلامات SQL، محول DDL إلى مخططات علاقات الكيانات (ER Diagrams)، ومولد مخططات قواعد البيانات.
- **DevOps والحاويات وإدارة النسخ:** مولد Docker Compose، مولد Dockerfile، مولد أوامر Git، مولد ملفات Gitignore، مولد package.json، حاسبة الإصدارات الدلالية (SemVer)، ومحول قواعد htaccess إلى Nginx.
- **تنسيقات الواجهة الأمامية و CSS:** حاسبة أوزان محددات CSS، مولد التايبوجرافي الانسيابي عبر `clamp()`، ومحول الوحدات القياسية.

*جميع الأدوات تعالج البيانات بالكامل من جانب العميل في المتصفح (حماية قصوى للخصوصية) ولها روابط سيو مخصصة (`/tools/{slug}/`).*

### ب) محاكي الأكواد التفاعلي متعدد اللغات (15 لغة برمجة)
بيئة برمجية تفاعلية مدمجة داخل الدروس تتيح للطلاب كتابة وتجربة 15 لغة برمجة مباشرة:
- **اللغات المدعومة:** Python, JavaScript, TypeScript, C, C++, C#, Java, Go, Rust, PHP, Ruby, Kotlin, Swift, SQL, Bash.
- **معمارية المحركات المتعددة القابلة للتوسع:** نظام تجريد مستقل يفصل واجهة المحرر عن مشغلات التشغيل الخارجية (Piston, Judge0, JDoodle, Null Driver).
- **أمان مضيف الخادم بنسبة 100%:** سياسة حظر صارمة تمنع تنفيذ أي كود داخل خادم ووردبريس المحلي، مع فحص آلي دائم يضمن خلو الشيفرة من دوال التقييم والتنفيذ المباشر.
- **روابط مخصصة للسيو:** مسار مستقل ومحسّن لمحركات البحث لكل لغة (`/editor/{lang}/`).

### ج) نظام العضويات والتحفيز وتتبع التقدم التعليمي
محرك تحفيز تعليمي متطور مبني مباشرة فوق نواة مستخدمي ووردبريس:
- **مصادقة أصيلة خفيفة:** إدارة تسجيل الدخول وإنشاء الحسابات واستعادة كلمة المرور ولوحة العضوية دون الحاجة لإضافات عضويات خارجية ثقيلة.
- **سجل النقاط الذري غير القابل للتكرار (Idempotent Points Ledger):** تسجيل كل حركة نقاط في جدول مخصص محمي بقيد فريد (`idempotency_key`) يمنع مضاعفة النقاط عبر سباق الطلبات.
- **متتبع القراءة النشطة الفعلي:** قياس التفاعل الحقيقي للزائر بالاعتماد على واجهة Page Visibility API ونسبة التمرير لمنع التحايل بترك الصفحة في الخلفية.
- **محركات الالتزام اليومي والشارات:** تتبع سلاسل الأيام المتتالية (Streaks)، ومكافآت الإنجاز، وسجل إتمام الدروس، و11 شارة استحقاق معتمدة.

### د) جناح صحة الـ SEO وحماية حركة المرور
نظام رصد وتحصين مصمم لحماية أرشفة محركات البحث وحركة الزوار:
- **سجل وتحليل فوري لأخطاء 404:** التقاط الروابط المكسورة فور حدوثها لتشخيص أي روابط تالفة.
- **محرك توجيه 301 التلقائي:** الحفاظ على قوة الروابط السابقة وعصارة السيو عند إعادة هيكلة المسارات.
- **سياسات الفهرسة الدقيقة والروابط المعيارية:** فرض الروابط المعيارية (Canonical URLs) وحظر فهرسة صفحات البحث أو الأرشيفات الضعيفة.
- **توليد تلقائي للبيانات المنظمة Schema.org:** دعم تنسيقات JSON-LD للمقالات التعليمية والكورسات ومسار التتبع.
- **أوامر WP-CLI متخصصة:** فحص وتدقيق صحة السيو والأرشفة مباشرة من سطر الأوامر.

### هـ) محرك أنماط كتل Gutenberg
- تصنيف كتل خاص باسم: **أنماط كود التطور | Code Elta6ur Patterns**.
- أنماط مصممة مسبقاً تشمل: بانرات الهيرو، شبكة المميزات، بطاقات الكورسات، أقسام الدعوة لاتخاذ الإجراء، وبطاقات الأكواد المجهزة بزر النسخ بنقرة واحدة.
- استغناء تام عن بناة الصفحات المرئية في بناء وتصميم كافة الصفحات الجديدة.

| التحدي الهندسي | الحل المنفذ في القالب |
| :--- | :--- |
| **بطء التحميل الناتج عن أطر العمل** | التخلص من jQuery و Bootstrap و React في واجهة الزائر، والاعتماد على Vanilla JS النقي و CSS Custom Properties، مما حقق سرعات تحميل قياسية. |
| **التعايش مع صفحات Elementor السابقة** | بناء غلاف برمجي ذكي وطبقة أنماط معزولة تضمن بقاء الصفحات القديمة سليمة تماماً دون أن تؤثر على خفة الصفحات الجديدة. |

| **محاولات الاحتيال وتكرار النقاط** | تطبيق مبدأ Zero-Trust بحساب النقاط بالكامل على الخادم وفرض قيود منع التكرار البرمجية وقواعد البيانات الفريدة. |
| **انعكاس الواجهات العربية والإنجليزية** | استبدال الاتجاهات الثابتة بالخصائص المنطقية الحديثة في CSS (`margin-inline`, `padding-inline`) لدعم الاتجاهين بسلاسة فائقة. |

## 6. التحقق المؤتمت وضمان الجودة (QA)

خضعت المنصة للتحقق عبر جناح فحص آلي مستقل:
- **مشغل الاختبارات المستقل (`run-all-tests.php`):** أداة CLI تفحص سلامة تسجيلات الأدوات، ومحركات التشغيل، ومطابقة البيانات دون الاعتماد على بيئة إنتاج حية.
- **الفحص الأمني الثابت:** فحص برمجي شامل يتأكد من انعدام دوال التقييم والتنفيذ المباشر الخطرة في كل ملفات القالب.
- **فحص التوافق النحوي (Linting):** توافق بنسبة 100% مع إصدارات PHP 8.0 و 8.1 و 8.2 و 8.3 ومعايير ووردبريس البرمجية الرسمية.
- **فحوصات التجاوب البصري وإمكانية الوصول:** فحص شجرة الـ DOM والتجاوب على مختلف مقاسات الشاشات وتباين الألوان.
- **سلامة حزم الإنتاج:** فحص سلامة حزم ZIP التوزيعية وخلوها من ملفات التطوير.

للاطلاع على التفاصيل، راجع [docs/ar/testing-and-qa.md](docs/ar/testing-and-qa.md).
